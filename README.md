# JavobBot AI

Telegram Business uchun shaxsiy AI yordamchi.

## MVP
- Telegram Business xabarlarini qabul qilish
- Oddiy savollarga AI orqali avtomatik javob berish
- Muhim xabarlarni admin tasdig'iga yuborish
- Har bir chat uchun alohida suhbat xotirasi

## Talablar
Python 3.12+, Telegram bot token, OpenAI API key, PostgreSQL.

## Holat
Boshlang'ich loyiha tuzilmasi yaratilmoqda. Maxfiy kalitlarni `.env` orqali kiriting; ularni GitHub'ga joylamang.
